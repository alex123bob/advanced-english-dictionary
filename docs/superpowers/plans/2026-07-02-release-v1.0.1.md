# Chrome Extension v1.0.1 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bump the Chrome extension to version 1.0.1, rebuild the distribution, create a signed git tag, and publish a GitHub release with the zip artifact.

**Architecture:** Version bump in source files → clean rebuild → repackage zip → git commit + tag → GitHub release with attached zip.

**Tech Stack:** Node.js (build script), zip CLI, git, GitHub CLI (`gh`)

---

### Task 1: Bump version in source files

**Files:**
- Modify: `clients/chrome-extension/src/manifest.json`
- Modify: `clients/chrome-extension/package.json`

- [ ] **Step 1: Update manifest.json version**

In `clients/chrome-extension/src/manifest.json`, change:
```json
"version": "1.0.0",
```
to:
```json
"version": "1.0.1",
```

- [ ] **Step 2: Update package.json version**

In `clients/chrome-extension/package.json`, change:
```json
"version": "1.0.0",
```
to:
```json
"version": "1.0.1",
```

- [ ] **Step 3: Verify the changes**

Run:
```bash
grep '"version"' clients/chrome-extension/src/manifest.json clients/chrome-extension/package.json
```

Expected output:
```

clients/chrome-extension/package.json:  "version": "1.0.1",
```

### Task 3: Repackage the zip artifact

**Files:**
- Modify: `clients/chrome-extension/dist.zip`

- [ ] **Step 1: Remove old zip**

```bash
rm -f clients/chrome-extension/dist.zip
```

- [ ] **Step 2: Create new zip from dist/ contents**

```bash
cd clients/chrome-extension/dist && zip -r ../dist.zip .
```
Expected: zip is created with all dist files.

- [ ] **Step 3: Verify zip contents include manifest.json**

```bash
unzip -l clients/chrome-extension/dist.zip | grep manifest.json
```
Expected: a line showing `manifest.json` in the zip.


### Task 5: Create and push git tag

- [ ] **Step 1: Create annotated tag**

```bash
git tag -a v1.0.1 -m "Chrome extension v1.0.1

- Fix Google Fonts loading in China (replaced with loli.net mirror)
- Add bilingual (zh-cn) UI and localization support
- Add /home portal pages
- Update extension defaults and homepage copy"
```

- [ ] **Step 2: Push tag and commit to origin**

```bash
git push origin main --tags
```
Expected: pushes the commit and the `v1.0.1` tag.

- [ ] **Step 3: Verify tag exists on remote**

```bash
git ls-remote --tags origin v1.0.1
```
Expected: shows refs/tags/v1.0.1.

---

### Task 6: Create GitHub release

- [ ] **Step 1: Create release with zip attached**

```bash
gh release create v1.0.1 \
  clients/chrome-extension/dist.zip \
  --title "Chrome Extension v1.0.1" \
  --notes "## What's Changed

- **China accessibility:** Replace Google Fonts CDN with loli.net mirror for users in China
- **Bilingual UI:** Add zh-cn localization and language selector
- **Home portal:** Add /home landing pages
- **Defaults & copy:** Update extension defaults and homepage copy"
```
Expected: outputs a GitHub release URL.

- [ ] **Step 2: Verify release**

```bash
gh release view v1.0.1
```
Expected: shows release title, notes, and attached `dist.zip` asset.
