# iOS App Client

SwiftUI starter for an iPhone/iPad dictionary app. The source uses the same API model as the macOS starter while presenting a compact mobile-first lookup flow.

## Included

- `AdvancedDictionaryIOSApp.swift`: app entry point.
- `DictionarySearchView.swift`: mobile search interface with recent lookups.
- `DictionaryAPI.swift`: API client and response models for `/api/dictionary`.

## Next Integration Step

Create an Xcode iOS App project and add the files in `Sources/AdvancedDictionaryIOS/` to the app target.
